# Results

Real paper/benchmark numbers are intentionally not fabricated in this public-ready package.

When you rerun the cleaned code on the exact experiment protocol, commit only the final audited aggregate results and figures. Recommended fields:

- method
- thread count
- latent rank
- validation RMSE
- final test RMSE
- training time
- speedup relative to one thread

`example_metrics.csv` only documents the output schema and is **not** a scientific result.
