# Publication-safety note

The uploaded research code contains the full A-ASGD implementation. This public-ready repository deliberately **does not expose that implementation** because its publication/release status was not established in the uploaded materials.

Before releasing the A-ASGD source, confirm with your supervisor/coauthors that:

- the paper/code can be made public;
- there are no double-blind review constraints;
- there are no institutional or sponsor IP restrictions; and
- the public implementation matches the version described in the paper.

Once approved, add the algorithm as a separate source file and document the exact paper protocol and citation.
